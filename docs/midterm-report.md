## 2. 학습 데이터 다양화 (M1, 피드백: "평가셋과 독립된 기준으로 다양화")

- 연도: 명시 40% / 생략 45% / 상대 표현("올해 보고서 기준", "전년 대비") 15%

## 6. 재정렬기 (M6, 대안 경로)
같은 M1 쌍으로 cross-encoder를 학습했다: (질문, positive) = 1, 저장된 negative 최대 3개 = 0, 16,093행. BCE, lr 2e-5, batch 16, 1 epoch, 입력 512토큰. RRF+필터 top-20을 다시 정렬한다.

  - 답 없는 질문 문장 5건 (LLM 머리말 섞임, 임원 소유주식처럼 일부 공시되는 정보 → 명백히 없는 정보로).
  - 답 문장 오류 1건 (검색 평가 영향 없음).
- **폐기 3건:** 정답 청크가 회계기준 개정·손상 회계정책 문단이라 질문에 답하지 않음.

**대행 문항 60개:** 단일 수치 8 / 연도 비교 16 / 기업 비교 16 / 서술 12 / 답 없음 8. 가이드라인 4절대로 질문을 먼저 쓰고 근거를 찾았다.
- 별칭(하이닉스·한전·기아차·SKT·KB국민은행), 브랜드(업비트 운영사), 기수(제22기), 구어체를 섞었다.
- 수치 정답은 OpenDART 값을 썼다. 새 회사 쌍(삼성전자–LG전자)을 넣었고, 서술 비교 문항(두 연도, 두 회사)도 만들었다.
- **한계:** 쓴 사람(Claude)이 코퍼스와 시스템을 이미 본 상태라 진짜 "원문을 안 보고 쓴 질문"이 아니다.

**구성 (살아 있는 197문항):** 단일 40 / 연도 비교 48 / 기업 비교 48 / 서술 41 / 답 없음 20.

- 검색 평가는 정답 청크가 있는 문항만 쓴다: dev 43, test 134 (LLM 95 + 대행 39).

**유형별 R@5 (test):**

|---|---|---|---|---|

| 최종 (bge-ft) | 0.862 | 0.778 | 0.200 | 0.931 |

**해석**
- **자체 평가셋에서는 미세조정 임베딩이 공개 KURE보다 유의하게 좋다** (RRF+필터 R@5 +15.7%p).
  - FinDartBench test에서는 전체로 유의차가 없었고(+1.8%p), 연도가 있는 질문에서만 유의했다(+8.6%p). 자체 평가셋은 가이드라인상 모든 질문에 회사·연도가 있으므로, 두 결과는 같은 이야기다: **미세조정 이득은 회사·연도가 명시된 질문에서 나온다.**
  - 대행 문항(39)만 봐도 MRR 차이는 유의하다(+12.2). R@5는 CI 하한이 0이라 경계선이다.
- **직접 학습한 KLUE 재정렬기**는 M3 hard RRF+필터 대비 R@5 +12.0%p다(전체 0.455 → 0.575). 출처별로도 둘 다 유의하다.
  - bge-ft(공개 재정렬기 미세조정)가 가장 좋다. 반면 학습 없는 bge-zero는 거의 효과가 없다 (R@5 0.455 → 0.455).
  - 즉 **재정렬기도 우리 학습 쌍으로 학습해야 효과가 난다.**
- **기업 비교는 최종 시스템도 R@5 0.20**이다. 두 회사 근거가 필요한데 질문 하나로 한 번 검색하기 때문이다. 회사별 하위 질문으로 나눠 검색하는 방식이 다음 과제다.
- **주의할 점**
  - 수치 문항(단일·연도·기업 비교 113/134)이 많고, 학습 쌍의 숫자 질문 형식과 가깝다. LLM 문항은 템플릿을 바꿔 쓴 것이고, 대행 문항은 Claude가 썼다.
  - 같은 회사·연도의 요약재무 청크를 많은 문항이 공유해서, 문항 단위 CI는 실제보다 좁을 수 있다.
  - 팀이 쓴 진짜 사람 문항으로 다시 재야 한다.
- **발견: 메타데이터 추출 누락.** 대행 서술 문항 10개가 "2024 사업보고서"처럼 연도 뒤에 바로 "사업보고서"를 붙여 썼는데, 추출기가 이를 연도로 뽑지 못해 필터가 꺼졌다.
  - 이 표현은 "2024 사업연도 보고서"와 "2024년에 낸 보고서(2023 사업연도)" 두 가지로 읽혀서 실제로도 모호하다.
  - test 전에 규칙을 고치지 않았다. dev 문항으로 규칙(사업연도로 해석 + 확인 질문)을 정한 뒤 다시 잰다.
