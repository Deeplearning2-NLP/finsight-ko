## 한 줄 메시지
"사업보고서 질문은 '어느 회사 몇 년'을 구분하는 검색과 표 숫자 계산이 어렵다. 우리는 검색 모델을 직접 학습해 앞의 문제를, OpenDART 조회와 Python 계산으로 뒤의 문제를 풀었다(수치 정답률 4% → 96%)."

## 강조할 것 / 피할 것
- **강조**
  - 직접 학습 모델 두 종류(임베딩, 재정렬기)가 있다.
  - 기준선과 같은 test로 비교했다.
  - 좋지 않은 결과(FinDartBench 전체 유의하지 않음)도 그대로 보고한다.
- **피할 것**
  - 95.8%를 "LLM이 잘했다"로 말하지 않는다. 숫자는 OpenDART + Python이 정하고, LLM은 계획과 설명만 한다.
  - FinDartBench R@1 +19%p를 미세조정 효과로 말하지 않는다. 이 이득은 연도 규칙에서 나왔다.
