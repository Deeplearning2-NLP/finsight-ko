## Q2. P4 결과의 통계적 검정
- test 1,947문항에서 쌍 비교 McNemar (R@1, R@5): 공개 KURE vs 미세조정 KURE, 형태소 BM25 vs 미세조정 KURE, 미세조정 KURE vs RRF.
- 질문들이 근거 문단을 공유해서 독립이 아니므로 **문단 단위 클러스터 부트스트랩**(문단을 복원 추출, 1,000회, seed 42)으로 R@5·MRR 차이의 95% 신뢰구간도 계산. McNemar p값과 나란히 보고하고, 어느 쪽이 더 보수적인지 한 줄로.

## Q3. 연도 혼동 진단 실험 (학습 없이, 원인 분리)
P4에서 1위 결과의 29.4%가 같은 회사·같은 섹션의 다른 사업연도였다. 원인을 숫자로 분리한다.
- (a) **회사 필터:** 질문의 회사(FinDartBench `company`)로 검색 범위를 제한.
- (b) **회사 + 사업연도 필터:** 근거 문단이 매핑된 보고서의 `fiscal_year`까지 제한 → 정답 연도를 아는 **상한(oracle)**. 실제 시스템에선 질문에 연도가 명시될 때만 가능하다고 명시.
- (c) **연도 중복 제거:** 같은 회사·같은 섹션 경로에서 거의 같은 청크(5-gram Jaccard ≥ 0.9)가 여러 연도에 있으면, 어느 연도든 맞히면 정답으로 치는 "관대한" 지표도 함께.
- 방법 5개(공백 BM25, Kiwi BM25, 공개 KURE, 미세조정 KURE, RRF) × 조건(필터 없음 / a / b), R@1·R@5·MRR. 그리고 (c) 관대한 지표.
- 읽는 법 한두 줄: 연도 혼동을 없애면 얼마나 오르는가 → "질문에 사업연도를 명시 + 메타데이터 필터"와 "연도 hard negative 학습"의 기대 효과.

## Q4. 오류 분석 30건 (교수님 "꼭 할 것")
- 최고 시스템(RRF, 필터 없음)의 test 실패(정답이 top-5 밖) 중 seed 42로 30건 무작위 추출. 질문, 정답 청크 앞부분, 1위 청크 앞부분을 나란히 `outputs/proposal/error_analysis_30.md`에.
- 각 건을 직접 읽고 유형 분류: 다른 사업연도 / 같은 회사 다른 섹션 / 다른 회사 같은 주제 / 표·숫자 질문(표 텍스트화 문제) / 질문이 모호(회사·연도 없음) / 정답 라벨·매핑 문제 / 기타. 한 건에 주 유형 1개 + 부 유형.
- 유형별 건수 표와 대표 예 1개씩을 결과 문서에. 유형마다 "본 실험에서의 대응" 한 줄.
- 숫자를 세는 것보다 **왜 틀렸는지** 문장으로 쓰는 게 핵심.

## Q5. 평가셋 작성 가이드 (문서, 팀 공용)
`docs/eval_guideline.md`:
- 5유형별 정의, 정답 형식, 근거 청크 ID 기록법(`chunk_id`, 여러 개 허용), 사업연도·회사·연결/별도 명시 규칙, 재작성 규칙(Q1).
- **사람이 직접 쓰는 문항(약 30%) 작성법:** 원문을 보지 않고 먼저 질문을 쓴 뒤 근거를 찾기(원문 단어 베끼기 방지), 비교형 위주, 예시 3개.
- 검수 체크리스트(질문이 명확한가 / 정답이 하나인가 / 근거가 실제로 답을 담는가), 판정(통과/수정/폐기), 30문항 교차 검수와 일치도(Cohen's κ) 계산법.
- `data/eval/` 파일 형식(JSONL 필드)과 `generated_by`(template / llm:<모델명> / human:<이니셜>) 표기.

## Q6. (시간 되면) 학습 쌍 생성 파이프라인 파일럿 — 9주차 선행
- Dartdoc에서 **평가 10개사를 뺀** 회사 중 FY2022–2024가 모두 있는 회사 20개를 업종이 섞이게 고르고, 회사·연도당 섹션 II·IV 청크 몇 개씩 → 512토큰 이하로 재분할.
- 서버 오픈 모델(Qwen 계열 7–8B instruct, vLLM)로 청크마다 질문 1–2개 생성. 프롬프트 규칙: 회사명·사업연도를 질문에 넣기, 원문 문장을 그대로 베끼지 않기, 청크만으로 답할 수 있는 질문, 숫자 질문 일부 포함. 모델 이름·버전·프롬프트·디코딩 설정을 기록.
- 파일럿 300쌍 생성 → 무작위 30쌍을 직접 읽고 품질 판정(답 가능 / 베끼기 / 모호 / 오류) 비율 보고. 원문과 질문의 단어 겹침(Kiwi 내용어 Jaccard) 분포도.
- 같은 회사·같은 섹션의 **다른 사업연도 청크**를 hard negative로 붙인 학습 파일 형식까지 만들고 저장(`data/train/pairs_pilot.jsonl`). 본 학습은 하지 않는다.
- 디스크: 모델은 NFS의 HF 캐시에, 생성 결과는 `data/train/`.
