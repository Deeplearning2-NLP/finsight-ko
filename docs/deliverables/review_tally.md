# 사람 검수 집계

`scripts/tally_human_review.py --consensus`로 생성. 비율 옆 괄호는 Wilson 95% 신뢰구간. **3인(임병건·백윤우·박채영) 합의 판정이며, 독립 κ가 아니다.**

## 학습 쌍 사람 검수 (99쌍, 3인 합의 판정)

- 판정 완료 99/99쌍 (미판정 0)

| 판정 | 비율 [95% CI] |
|---|---|
| 답가능 | 54/99 = 54.5% [44.8%, 64.0%] |
| 베끼기 | 4/99 = 4.0% [1.6%, 9.9%] |
| 모호 | 27/99 = 27.3% [19.5%, 36.8%] |
| 오류 | 14/99 = 14.1% [8.6%, 22.3%] |
| **사용 가능 (답가능+베끼기)** | 58/99 = 58.6% [48.7%, 67.8%] |
| **오류** | 14/99 = 14.1% [8.6%, 22.3%] |
