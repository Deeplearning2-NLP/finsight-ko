# 사람 검수 집계

`scripts/tally_human_review.py`로 생성. 비율 옆 괄호는 Wilson 95% 신뢰구간.

## 학습 쌍 사람 검수 (99쌍, 3명)

- 판정 완료 99/99쌍 (미판정 0)

| 판정 | 비율 [95% CI] |
|---|---|
| 답가능 | 54/99 = 54.5% [44.8%, 64.0%] |
| 베끼기 | 4/99 = 4.0% [1.6%, 9.9%] |
| 모호 | 27/99 = 27.3% [19.5%, 36.8%] |
| 오류 | 14/99 = 14.1% [8.6%, 22.3%] |
| **사용 가능 (답가능+베끼기)** | 58/99 = 58.6% [48.7%, 67.8%] |
| **오류** | 14/99 = 14.1% [8.6%, 22.3%] |

- 겹친 15쌍 일치도: Cohen's κ = 1.00, 일치율 p_o = 100.0% (두 명 모두 판정한 15쌍)

| 질문 종류 | n | 사용 가능 | 오류 |
|---|---|---|---|
| 숫자 질문 | 33 | 15/33 = 45.5% [29.8%, 62.0%] | 6/33 = 18.2% [8.6%, 34.4%] |
| 서술 질문 | 66 | 43/66 = 65.2% [53.1%, 75.5%] | 8/66 = 12.1% [6.3%, 22.1%] |
