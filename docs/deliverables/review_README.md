# 사람 검수 시트 사용법 (11/19 밤, 23:00까지)

CSV를 구글시트에 붙여 넣거나 가져오기(파일 → 가져오기 → 업로드)로 열고, 빈 칸만 채운 뒤 **CSV로 다시 내보내 같은 파일 이름으로** 주세요. 다른 열은 고치지 마세요.

## 1. 학습 쌍 (`review_pairs_<이름>.csv`, 1인 38행, 약 40분)
| 담당 | 파일 |
|---|---|
| 임병건 | `review_pairs_임병건.csv` |
| 백윤우 | `review_pairs_백윤우.csv` |
| 박채영 | `review_pairs_박채영.csv` |

- 질문과 정답 청크(본문)를 읽고 **판정** 칸에 아래 넷 중 하나를 적습니다. **이유** 칸에는 한 줄을 씁니다(답가능이면 비워도 됩니다).
  - **답가능:** 그 청크만 읽고 질문에 분명히 답할 수 있다.
  - **베끼기:** 답할 수는 있지만 질문이 청크 문장을 거의 그대로 옮겼다.
  - **모호:** 여러 답이 가능하거나, 질문이 무엇을 묻는지 불분명하다.
  - **오류:** 청크로 답할 수 없다. 또는 질문의 회사·연도·숫자가 청크와 다르다.
- "질문 형식" 열이 "연도 생략", "상대 표현(올해 등)"이면, 질문에 연도나 회사가 빠진 것은 일부러 그렇게 만든 형식입니다. 그것만으로 오류가 아닙니다.
- 38행 중 5행은 다른 사람 시트와 겹칩니다(일치도 κ 계산용). 어느 행인지는 표시하지 않았으니 서로 상의하지 말고 판정해 주세요.

## 2. 평가셋 (`review_eval_<이름>.csv`, 30행, 약 40분)
| 담당 | 파일 |
|---|---|
| 백윤우 | `review_eval_백윤우.csv` |
| 박채영 | `review_eval_박채영.csv` |

- 두 사람에게 **같은 30문항**이 순서만 바뀌어 들어 있습니다(유형별 6개). **서로 보지 않고** 따로 판정해 주세요.
- 체크 세 칸은 Y 또는 N입니다(`docs/eval_guideline.md` 5절).
  - **질문 명확:** 회사·사업연도·(수치면) 연결/별도가 있고, 두 가지로 읽히지 않는다.
  - **정답 하나:** 다른 청크나 다른 해석으로 다른 답이 나오지 않는다. 재작성 값은 "허용"으로 적혀 있으면 하나로 칩니다.
  - **근거 맞음:** 근거 청크만 읽고 정답을 확인할 수 있다. 근거 청크는 최대 3개만 보여 주고, 나머지 ID는 "외 N개"로 적었습니다.
- **판정:** 통과(세 칸 모두 Y) / 수정(고치면 통과, 메모에 어떻게 고칠지) / 폐기(정답이 없거나 둘 이상, 근거가 없음).
- 답 없는 질문은 근거가 없는 것이 정상입니다. "사업보고서에 정말 없는 정보인가"를 보고 판정하세요.

## 집계
채운 CSV를 이 폴더에 덮어쓴 뒤:
```bash
.venv/bin/python scripts/tally_human_review.py
```
→ `docs/deliverables/review_tally.md`가 생깁니다. 담긴 내용은 다음과 같습니다.
- 학습 쌍 오류율·사용 가능 비율(95% CI)과 겹친 15쌍의 κ
- 평가셋 판정 분포와 κ
- 유형별·출처별(LLM 초안 vs Claude 대행 문항) 통과율

시트 재생성은 `scripts/make_review_sheets.py`(seed 42)입니다. 다시 돌리면 채운 칸이 지워지니 주의하세요.
