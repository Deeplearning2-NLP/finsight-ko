# 교수님 피드백 대응표 (2026-10-18 프로포절 전 피드백)

발표(10/23)에서 "지적 사항을 어떻게 해결했는가"를 이 표로 보여준다. 상태가 바뀌면 갱신한다.
상태: ✅ 완료 · 🟡 진행 중 · ⬜ 미착수

## 평가 설계 (사전 질문 답변)
| 피드백 | 우리 대응 | 상태 |
|---|---|---|
| 검색 / 수치 / 서술형 3갈래 평가 | 검색 Recall@k·MRR (근거 청크 ID) / 수치 OpenDART 자동 비교 / 서술형 사람 평가 (LLM judge는 30문항 사람 채점과 일치도) | ✅ 계획 |
| 200문항, CI ±7%p, McNemar | 유형 5 × 40, 작은 차이는 McNemar 또는 한계로 명시 | ✅ 계획 |
| 검증 50 / 테스트 150 | 분할 파일 고정, test는 마지막 1회 | ✅ 계획 |
| 약 30% 사람 작성, 점수 분리 보고 | 비교형 위주로 사람 작성 | ✅ 계획 |
| 답 없는 질문 약 10% | 포함 | ✅ 계획 |
| 검수 기준 + 30문항 교차 검수 | 기준: 질문 명확성 / 정답 단일성 / 근거 정확성 | ⬜ 기준 문서 작성 |
| AutoRAGRetrieval은 보조, 결론은 자체 평가셋 | 동일 (LLM 생성 질문의 BM25 편향 확인됨) | ✅ |
