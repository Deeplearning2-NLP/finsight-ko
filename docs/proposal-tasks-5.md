## S1. 회사 분리 미세조정 (본 학습 1차)
- R2 파이프라인으로 `corpus_train.jsonl`(20개사 원문)에서 **약 5,000쌍** 생성 (같은 Qwen 모델·프롬프트·필터: 숫자 불일치·회사/연도 누락 제거). 생성 쌍은 `generated_by: llm:<모델명>`, **사람 검수 0%**로 표시 (R2 30쌍 판정 80%는 별도 근거로 인용).
- 두 설정을 같은 하이퍼파라미터(스모크와 동일: CachedMNRL, 1 epoch, max 512, seed 42)로 학습:
  - (a) in-batch negative만
  - (b) (a) + **같은 회사·같은 섹션의 다른 사업연도** hard negative 1개 (R2 필터: 답·숫자 포함 후보, 5-gram Jaccard ≥ 0.8 제외)
- 평가: P4와 같은 조건(원문 34,427청크, FinDartBench test 1,947문항). 학습에 평가 10개사 청크·문항이 전혀 없음을 assert. 체크포인트 선택이 필요하면 dev로.
- 보고: 공개 KURE / 스모크(같은 회사) / (a) / (b) — R@1·R@5·MRR, 그리고 RRF(Kiwi BM25 + 각 모델), RRF + R1 메타데이터 필터.
- 공개 KURE 대비 (a)·(b), (a) 대비 (b)의 **문단 클러스터 부트스트랩 95% CI** (Q2와 같은 방법).
- **연도 혼동 지표:** 1위 청크가 "같은 회사·같은 섹션의 다른 사업연도"인 비율 (P4 RRF 29.4%와 같은 정의)을 공개 KURE / (a) / (b)로. hard negative가 이 비율을 줄였는지 한 줄.
- 결과가 공개 KURE보다 나빠도 그대로 보고하고, 이유 추정(도메인 차이·질문 스타일 차이: 생성 질문 vs FinDartBench 질문) 한두 줄.
- 학습 시간·GPU 메모리 기록.
