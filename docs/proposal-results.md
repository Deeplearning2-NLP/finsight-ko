## 4. 보고서 1개 파싱·청킹, 표 포함 (T3, 꼭 할 일 4번 전반)
`scripts/opendart_parse_one.py`, 대상: 삼성전자 사업보고서 (2024.12), rcept_no 20250311001085 (`corpCode.xml` → corp_code 00126380 → `list.json` → `document.xml`).

- 원문 ZIP 안의 XML 3개 (본문 6.3MB + 첨부 2개). 목차는 `SECTION-1/2/3` + `TITLE`로 나뉜다. 본문은 `P`, 표는 `TABLE/TR/TD·TH·TE·TU`.
- 파싱 결과: 본문 블록 2,070개, 표 1,052개. II 사업의 내용: 본문 145블록(26,203자) + 표 60개 / IV 경영진단: 본문 48블록(10,835자) + 표 19개.

  - 단위는 표 바로 앞의 1행짜리 표 "(단위 : 백만원)"에 들어 있다. 표 안에 있는 "(단위 : 원)"(주당이익 행 주석)을 단위로 잡으면 값이 100만 배 틀어진다 → 바로 앞 단위 표를 우선 적용.
  - 재무제표 주석은 "표 안에 본문과 표가 다시 들어 있는" 레이아웃 표다 → 중첩 표·긴 셀은 본문으로 풀어 처리.
  - `ROWSPAN`/`COLSPAN`은 격자로 펼친다.

- 본 실험 계획: Dartdoc·원문 청크에서 LLM으로 질문을 만들어(생성 LLM ≠ 시스템 LLM, 검수 비율 기록) 수천 쌍을 만들고, **같은 회사 다른 사업연도 문단을 hard negative로**, 평가 회사·기업-연도와 겹치지 않게 다시 학습한다. 비교는 자체 평가셋으로.

### 9.4 원문 코퍼스에서 검색 다시 재기 (P4)
- **정답 청크 매핑 (문자 겹침, LLM 없음):** 마크다운 기호와 공백을 지운 문자 5-gram. FinDartBench 근거 문단마다 같은 회사 보고서 중 겹침이 가장 큰 보고서를 고르고, 그 보고서 안에서 청크의 5-gram이 문단에 50% 이상 포함되면 정답 청크로 삼았다. 정답 청크들이 문단의 50% 이상을 덮으면 매핑 성공으로 쳤다.
  - 근거 문단 195개 중 **186개 매핑 (실패율 4.6%)**, 문항 기준 5,491 / 5,638 (실패율 2.6%). 문단당 정답 청크 중앙값 4개(1–22), 정답 청크가 문단을 덮는 비율 중앙값 0.926 (하위 10%도 0.763).
  - 매핑된 문단 186개 중 181개가 FY2024 보고서다 (FY2023 4개, FY2022 1개) → FinDartBench는 사실상 FY2024 질문이다.
- T4와 같은 분할(`outputs/proposal/splits.json`)에서 매핑된 문항만 사용: dev 672 / **test 1,947.** 코퍼스는 30건 전체 34,427청크 (T4는 784청크). 지표 R@k = 정답 청크 중 하나라도 top-k에 있으면 맞음.
- RRF 조합(BM25 Kiwi 내용어 + 미세조정 KURE)은 dev MRR로 골랐다.

읽는 법:
- 코퍼스가 44배 커지자 R@1이 0.3 안팎으로 떨어졌다. **T4 숫자는 낙관적이었다**는 것을 실제로 확인했다.
- 순서는 그대로다: 형태소 BM25가 공개 KURE보다 조금 낫고 (R@5 0.615 vs 0.598), 스모크 미세조정이 둘 다 넘고 (0.653), RRF가 가장 좋다 (0.689). 공백 → Kiwi 내용어로 바꾸면 R@5 +17.0%p.
- **top-1 오답의 가장 큰 원인은 연도 혼동이다.** 가장 좋은 시스템(RRF)의 test top-1: 정답 581 (29.8%) / **같은 회사·같은 섹션의 다른 사업연도 청크 573 (29.4%)** / 같은 회사 다른 청크 404 / 다른 회사 389. FinDartBench 질문은 연도를 말하지 않는 경우가 많고, 같은 회사의 해마다 거의 같은 문단이 3개씩 있다.
  → 본 실험 설계 근거: ① 같은 회사 다른 사업연도 문단을 hard negative로 학습, ② 질문의 연도·회사로 메타데이터 필터링(`fiscal_year`, `corp_name` 필드는 이미 청크에 있음), ③ 자체 평가셋 질문에는 사업연도를 명시.
- 주의: 미세조정 모델은 FinDartBench train 문단으로 학습했다(test와 같은 10개사). 연도 혼동 573건 중에는 다른 연도 문단에 같은 답이 있는 경우도 섞여 있어서, 엄격한 지표다.
