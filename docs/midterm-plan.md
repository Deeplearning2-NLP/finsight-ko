## 실행 (2026-11-17)
- 파이프라인: `tmux new -d -s midterm 'bash scripts/midterm_run.sh'` (재시작해도 끝난 단계는 건너뜀, 진행 로그 `outputs/midterm/logs/pipeline.log`).

- 결과 파일: `outputs/midterm/eval_dev_*.json`, `selection_*.json`, `eval_test_final.json`, `rankings_*.json`(오류 분석용).

- 결과: `docs/midterm-report.md` (중간 발표 보고서).
