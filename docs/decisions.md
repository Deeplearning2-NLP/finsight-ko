## 2026-10-20 범위 확정 (안 A)
- 평가: FinDartBench 10개사 × 사업연도 2022–2024 사업보고서 30건, OpenDART 원문 파싱(표 포함)을 평가 코퍼스로. 이유: Dartdoc에는 이 중 7개사의 2022–2023 보고서가 없고, 표 숫자가 빠져 있음.
- 학습: Dartdoc에서 평가 10개사를 뺀 회사(3년 모두 있는 약 750개사) 청크로 LLM 질문을 만들어 미세조정 학습 쌍 생성 → 학습·평가 회사 분리.
- FinDartBench 기반 검색 결과(코퍼스 195문단)와 T6 미세조정 스모크(학습·테스트 같은 회사)는 **예비 결과**로만 쓴다. 결론은 원문 코퍼스 + 자체 평가셋으로.
- 답 없는 질문은 "범위 밖이지만 실제로는 공시된 정보"(예: FY2025)가 아니라 "사업보고서에 원래 없는 정보"로 만든다.

## 2026-10-19 교수님 피드백 반영

- LangGraph 에이전트·Streamlit 데모·Langfuse는 확장 목표(13주차 이후).
- 평가셋 200문항: 유형 5개 × 40, dev 50 / test 150, 약 30% 사람 작성, 답 없는 질문 약 10%.

- 범위는 업종별 10–20개사 × 3–5년 권고 → Dartdoc 집계 후 확정 (후보: FinDartBench 10개사 × 사업연도 2022–2024).
